# Кристал Клийн — сайт за почистване

Статичен сайт (HTML/CSS/JS) за професионално почистване на домове и офиси.
Еднократно и абонаментно почистване. **Без онлайн плащания** — клиентът плаща на място (в брой или по банков път).

## Страници

| Файл | Съдържание |
|---|---|
| `index.html` | Начало: еднократно vs абонамент, услуги, как работим, отзиви, въпроси, контакти |
| `uslugi.html` | Услуги (дом, офис, основно, след ремонт) и допълнителни услуги |
| `abonamenti.html` | Абонаментни планове (месечен / на 2 седмици / седмичен) и офис абонамент |
| `zayavka.html` | Форма за заявка (без цени — офертата се дава по телефона) |
| `poveritelnost.html` | Политика за поверителност |

## Настройки — `js/config.js`

Всичко, което се сменя често, е на едно място:

- име на фирмата, телефон, имейл, адрес, работно време
- видове почистване и допълнителни услуги (без цени — цената се дава индивидуално по телефона)
- абонаментни отстъпки

Хедърът и футърът се генерират от `js/main.js` с тези данни, така че контактите се сменят само тук.


## Получаване на заявките

Има три режима (в `js/config.js`), по ред на предимство:

1. **`appsScriptUrl`** — препоръчително. Всяка заявка идва на имейла на собственика
   с **прикачена оферта (Word .docx)** — попълва се цената и се изпраща на клиента с „Отговор“.
   Настройка: [`apps-script/НАСТРОЙКА.md`](apps-script/НАСТРОЙКА.md).
   Офертата се генерира от `js/offer-doc.js`.
2. **`formEndpoint`** — Formspree (https://formspree.io): заявката идва по имейл, без Word оферта.
3. Ако и двете са празни — бутонът отваря имейл с данните в пощенския клиент на посетителя.
## Пускане локално

Просто отворете `index.html` в браузър. Или стартирайте локален сървър:

```
npx serve .
```

## Публикуване

Качете цялата папка на произволен статичен хостинг — Netlify, Vercel, GitHub Pages, Cloudflare Pages
или обикновен споделен хостинг (FTP).
